# DSH 全量接入计划 — DeepSeek Harness 接入 T3 Code

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** 在 `T3 Code` 中一次性全量接入 `Hi-DSH deepseek-harness (b150a55)`，达到与 `Antigravity 1470行` 同标准的不阉割闭环：`HTTP POST /api + 双WS`、`思考/工具常驻`、`审批`、`附件`、`同线程切模型`、`中断/恢复`、`用量`，`typecheck 0` 后真连本机 `3080` 联调通过。

**Architecture:** 复用 `Effect` 驱动形态，对标 `AntigravityAdapter.ts 1470行` 与 `OpenCodeAdapter.ts`：`DshDriver` 只做探测与 `DshAdapterShape` 装配，`DshAdapter` 持 `fetch + WS` 双载体，`POST /api/session.*` 承载一元 RPC，`WS /api/events.mux+host` 只下行泵帧并映射为 `content.delta/item/approval/request` 等 `ProviderRuntimeEvent`，`DshProvider` 暴露 `llm.models/providers` 模型目录与 `session.selectModel` 同线程切。

**Tech Stack:** `T3 Code pnpm + Effect + Typert 4象限信封`、`Hi-DSH deepseek-harness @b150a55`、本机 `http://127.0.0.1:3080`（`npx @deepseek-ai/dsh web`）
